Este sistema de scripts trabaja por partes:

 * El IW `Instruction Write`, escribe intrucciones en el final del archivo.
 * El PC `Program Counter`, lee y lleva el control del registro de ejecucion.
 * El IC `Instruction Read`, interpreta la instrucción en la posición indicada por el PC.
